## 1. はじめに

Django ORMのダブルアンダースコア (`__`) は、「検索条件の指定（Lookup）」と「テーブル結合（リレーション横断）」などの区切り文字に使われます。

基本パターンは次の3つに集約され、`filter()`だけでなく`order_by()`や`values()`、`annotate()`などORM全体で共通して利用されます。

1. `field__lookup`（例: `price__gte=500` / 検索条件を指定）
2. `relation__field`（例: `author__name="夏目漱石"` / 外部キー先を参照）
3. `relation__field__lookup`（例: `author__name__icontains="漱"` / 外部キー先を検索）

:::note info
`relation`の表記について

`author__name`などの`relation`部分は、`ForeignKey`、`OneToOneField`、`ManyToManyField`、または逆参照（`related_name`等）といったモデル間のリレーション（関連）を定義しているフィールド名を指します。

`author`もモデル定義上はフィールドの一種ですが、単なる文字列や数値などの値ではなく「別モデルへの参照（テーブル結合/JOIN）」であることを明確にするため、本記事では`field__field`ではなく`relation__field`と区別して表記しています。

- `relation`：参照元の関連フィールド名（例: `ForeignKey`の`author`）
- `field`：リレーション先モデルのカラム名（例: `name`）
:::

- uv: 0.12.7
- Python: 3.14

## 3. 基本構文パターン

### 3.1 Lookup(検索条件)

フィールドに対する検索条件を指定します（クラス定義を含むサンプル全体は後述）。

```python
Book.objects.filter(title__contains="猫")
Book.objects.filter(price__gte=700)
```

代表例

- `__exact`
- `__iexact`
- `__contains`
- `__icontains`
- `__startswith`
- `__istartswith`
- `__endswith`
- `__iendswith`
- `__gt`
- `__gte`
- `__lt`
- `__lte`
- `__in`
- `__range`
- `__isnull`
- `__regex`
- `__iregex`
- `__year`
- `__month`
- `__day`
- `__week`
- `__week_day`
- `__quarter`
- `__date`
- `__time`

形式

```text
field__lookup=value
```

否定したい場合

- `exclude()`で一致するものを除外（例: `Book.objects.exclude(title="Django")`）
- `~Q()`（Qオブジェクトの否定）を使う（例: `Book.objects.filter(~Q(title="Django"))`）

代表例以外のLookup

- https://docs.djangoproject.com/en/6.1/ref/models/querysets/#field-lookups
- https://docs.djangoproject.com/en/6.1/topics/db/queries/#querying-jsonfield
- https://docs.djangoproject.com/en/6.1/howto/custom-lookups/

### 3.2 Relation Traversal(リレーション横断)

ForeignKey / OneToOneField / ManyToManyFieldを辿ります。複数段も可能です。

```python
Book.objects.filter(author__name="夏目漱石")
BookLog.objects.filter(book__author__name="夏目漱石")
```

形式

```text
relation__field
relation__relation__field
```

### 3.3 Reverse Relation(逆参照)

`ForeignKey`や`ManyToManyField`の定義元モデルを逆方向に辿って検索します。

```python
Author.objects.filter(book__title="吾輩は猫である")
```

:::note info
デフォルト名
デフォルトでは、QuerySet内は`<小文字モデル名>__<フィールド>`で逆参照します。

```python
Author.objects.filter(book__title="Django")
Group.objects.filter(user__email="asample@example.com")
Project.objects.filter(device__status="active")
```

:::

:::note info
related_nameを使う場合
`related_name`を明示的に付与して`books__title`のように参照すると、読みやすくなることがあります。

```python
class Book2(models.Model):
    author = models.ForeignKey(
        Author,
        on_delete=models.CASCADE,
        related_name="books",
    )
    title = models.CharField(max_length=100)

Author.objects.filter(books__title="Django")
```

:::

### 3.4 Relation Traversal + Lookup

リレーション先のフィールドに対して検索します。

```python
Book.objects.filter(author__name__contains="漱")
```

形式

```text
relation__field__lookup
```

### 3.5 JSONFieldのキー参照

JSONのキーを`__`で辿ることができます（キー名がLookup名と衝突する場合は使えません）。

```python
BookLog.objects.filter(data__tag=["小説"])
```

ネストしたキーも参照可能です。

```python
Book.objects.filter(booklog__data__tag=["小説"])
```

整数キーを使うと、配列要素を参照できます。

```python
BookLog.objects.filter(data__tag__0="小説")
```

形式

```text
jsonfield__key
jsonfield__key__nested_key
```

## 4. 各QuerySetメソッド・機能での利用

### 4.1 order_by()

関連先フィールドでソートします。

```python
Book.objects.order_by("author__name")
Book.objects.order_by("-author__name")
```

形式

```python
order_by("relation__field")
```

### 4.2 values() / values_list()

関連先フィールドを取得します。

```python
Book.objects.values("author__name")
Book.objects.values_list("author__name")
```

形式

```python
values("relation__field")
values_list("relation__field")
```

### 4.3 annotate() + F()オブジェクト

`annotate()`は、関連先フィールドを利用した注釈列を作成します。
F()オブジェクトはDB上でフィールド参照を行う書き方です。

```python
from django.db.models import F

Book.objects.annotate(
    author_name=F("author__name")
).values("author_name")
```

形式

```python
F("relation__field")
```

### 4.4 aggregate() / annotate() + Avg

関連先フィールドや逆参照を利用して集約できます。

```python
from django.db.models import Avg

Author.objects.aggregate(avg_price=Avg("book__price"))
Author.objects.annotate(
    avg_price=Avg("book__price")
).values("avg_price")
```

:::note info
補足

- `aggregate()`の例は全著者の平均を辞書で返す
- `annotate()`の例は著者ごとの平均をQuerySetで返す
- 実際の参照名は`related_name`の設定に依存する
:::

## 5. 注意点・制限事項

### 5.1 Constraint(制約)の制限

ConstraintではフィールドやLookupを利用できます。

```python
from django.db.models import Q
from django.db.models.constraints import CheckConstraint

CheckConstraint(
    condition=Q(price__gte=0),
    name="price_positive",
)
```

しかし、Djangoのデータベース制約はJOINをまたぐ条件を扱えないため、関連先フィールドを`CheckConstraint`で直接参照する設計はできません。

### 5.2 Index(インデックス)の制限

通常のIndexは同一テーブルのフィールドに対して作成します。

```python
models.Index(
    fields=["name"],
    name="name_idx",
)
```

しかし、`author__name`のようなJOIN先のフィールドに、`models.Index`で対象モデルから直接インデックスを作ることはできません。

### 5.3 その他

Lookupを省略すると`exact`になります。次の2行は同じ意味です。

```python
Book.objects.filter(title="Django")
Book.objects.filter(title__exact="Django")
```

リレーション横断では`select_related()`（主にForeignKey／OneToOne）や`prefetch_related()`（主にManyToMany）の利用も検討してください。

リレーションは複数段繋げて参照できますが、JOINの増加によるクエリ性能の低下や保守性の悪化を招くことがあります。`QuerySet.explain()`や実行時間を確認し、必要であればテーブル設計を見直すとよいでしょう。

## 6. まとめ

Django ORMにおいて特別な意味を持つ記法として、重要なのがダブルアンダースコア (`__`) です。

利用パターンは主に次の3種類です。

```text
field__lookup
relation__field
relation__field__lookup
```

`filter()`、`exclude()`、`get()`、`order_by()`、`values()`、`values_list()`、`annotate()`、`aggregate()`など多くのORM APIで利用できます。

## 7. 参考：サンプルコード

以下を`sample.py`とし、`uv run -p 3.14 -w django==6.1 sample.py`のように実行してください。

```python
import django
from django.conf import settings
from django.db import connection, models
from django.db.models import Avg, F

settings.configure(
    DATABASES={"default": {"ENGINE": "django.db.backends.sqlite3", "NAME": ":memory:"}},
    INSTALLED_APPS=["__main__"],
)
django.setup()


class Author(models.Model):
    name = models.CharField(max_length=100)

    def __str__(self) -> str:
        return self.name


class Book(models.Model):
    author = models.ForeignKey(Author, on_delete=models.CASCADE)
    title = models.CharField(max_length=100)
    price = models.IntegerField()

    def __str__(self) -> str:
        return self.title


class BookLog(models.Model):
    book = models.ForeignKey(Book, on_delete=models.CASCADE)
    date = models.DateField()
    data = models.JSONField()

    def __str__(self) -> str:
        return f"{self.date} {self.book}"


with connection.schema_editor() as schema_editor:
    schema_editor.create_model(Author)
    schema_editor.create_model(Book)
    schema_editor.create_model(BookLog)
author1 = Author.objects.create(name="夏目漱石")
author2 = Author.objects.create(name="宮沢賢治")
book = Book.objects.create(author=author1, title="吾輩は猫である", price=600)
Book.objects.create(author=author1, title="坊っちゃん", price=510)
Book.objects.create(author=author2, title="銀河鉄道の夜", price=750)
BookLog.objects.create(book=book, date="2026-09-01", data={"tag": ["小説"]})


print("\n### 3.1 Lookup(検索条件)")
print(f"{Book.objects.filter(title__contains="猫") = }")
print(f"{Book.objects.filter(price__gte=700) = }")

print("\n### 3.2 Relation Traversal(リレーション横断)")
print(f"{Book.objects.filter(author__name="夏目漱石") = }")
print(f"{BookLog.objects.filter(book__author__name="夏目漱石") = }")

print("\n### 3.3 Reverse Relation(逆参照)")
print(f"{Author.objects.filter(book__title="吾輩は猫である") = }")

print("\n### 3.4 Relation Traversal + Lookup")
print(f"{Book.objects.filter(author__name__contains='漱') = }")

print("\n### 3.5 JSONFieldのキー参照")
print(f"{BookLog.objects.filter(data__tag=["小説"]) = }")
print(f"{Book.objects.filter(booklog__data__tag=["小説"]) = }")
print(f"{BookLog.objects.filter(data__tag__0="小説") = }")

print("\n### 4.1 order_by()")
print(f"{Book.objects.order_by("author__name") = }")
print(f"{Book.objects.order_by("-author__name") = }")

print("\n### 4.2 values() / values_list()")
print(f"{Book.objects.values("author__name") = }")
print(f"{Book.objects.values_list("author__name") = }")

print("\n### 4.3 annotate() + F()オブジェクト")
print(
    f"{Book.objects.annotate(
    author_name=F("author__name")
).values("author_name") = }"
)

print("\n### 4.4 aggregate() / annotate() + Avg")
print(f"{Author.objects.aggregate(avg_price=Avg("book__price")) = }")
print(
    f"{Author.objects.annotate(
    avg_price=Avg("book__price")
).values("avg_price") = }"
)
```
